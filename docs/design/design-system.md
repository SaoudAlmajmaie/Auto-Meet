# Design System — [# Design System — AutoMeet]

## 1. Brand Principles
AutoMeet should feel clean, modern, and easy to use. The design should help users quickly find car shows and understand important event information without unnecessary clutter. The interface should feel welcoming to car enthusiasts while keeping navigation simple and clear.

## 2. Color Palette
| Name | Hex | Use |
|------|-----|-----|
| Primary | #1F4E79 | Main brand color, navigation, primary buttons |
| Secondary | #F28C28 | Accents, highlights, links |
| Background | #F7F9FC | Main page background |
| Surface | #FFFFFF | Cards, forms, and content sections |
| Text | #1F2937 | Main body text |

## 3. Typography

| Role | Font | Size | Weight |
|------|------|------|--------|
| Heading 1 | Arial | 32px | Bold |
| Heading 2 | Arial | 24px | Bold |
| Body | Arial | 16px | Regular |

## 4. Logo Usage

- File(s): Logo will be stored in the project assets folder when created.
- Do NOT: stretch, distort, recolor, crop, or place the logo on a busy background that makes it hard to read.

## 5. Spacing & Grid

- Base unit: 8px
- Grid/columns: 12-column layout with a maximum content width of 1200px
- Standard spacing scale: 8 / 16 / 24 / 32 / 48px

## 6. Core Components

| Component | Rules |
|-----------|-------|
| Button (primary) | Primary blue background, white text, 8px corner radius, 12px vertical and 20px horizontal padding |
| Button (secondary) | White background, primary blue border and text, 8px corner radius, 12px vertical and 20px horizontal padding |
| Card | White background, 1px light gray border, 16px padding, 8px corner radius |
| Form field | Label above input, clear focus state, 8px corner radius, error message shown below invalid input |
| Navigation | Primary blue background, simple labels, clear active state, responsive layout | 

## 7. Voice & Tone

- Tone: friendly, clear, and concise.
- Use simple language that is easy for users to understand.
- Avoid overly technical or formal wording in buttons, labels, and messages.
- Keep instructions short and direct.
- Example: use "View Event" instead of "Access Event Details."

## 8. Accessibility Standards

- Minimum contrast ratio: 4.5:1 for normal body text
- Standard to meet: WCAG 2.1 AA
- Use clear keyboard focus states for interactive elements.
- Form fields should include visible labels and understandable error messages.
- Images should include meaningful alt text when they provide important information.
